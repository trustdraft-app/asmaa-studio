# Figma Brief For Asmaa Studio

Create a premium Arabic-first landing page and social asset system for Asmaa Studio, a women-focused wedding videography business in Saudi Arabia's Eastern Province.

## Visual Direction

- Black cinematic background
- Champagne gold monogram treatment
- Warm ivory text
- Small rose/sage accents only for warmth
- Elegant but not over-decorated
- Mobile-first because traffic comes from Instagram, TikTok, and WhatsApp

## Screens

1. Mobile landing first viewport
2. Desktop landing first viewport
3. Package cards section
4. Instagram highlight cover set
5. Local SEO page template

## Must Preserve

- Brand name: Asmaa Studio
- Legacy handle: `@asmaa.video`
- Primary CTA: WhatsApp
- Service areas: الأحساء، الدمام، الخبر
- Tone: private, feminine, premium, clear

## Avoid

- Fake testimonials
- Overly bright bridal stock imagery
- Generic agency gradients
- Claims of affiliation with venues or government entities
